# PullQuote

A short belief in Elena's own words, set large, with a glowing quotation mark.

**Provide:** `<figure class="np-quote">` with a `<blockquote><p>` (one or two sentences) and a `<figcaption>` naming who said it.

- The quote is `ink`, 24/32, weight 600. The “ mark is `neon` Fira Sans at 96px with a `neon-glow` halo, and is hidden from screen readers.
- Use one per section, and only for real quotes, never invented testimonials.
- Don't add a coloured left border or a card behind it.
