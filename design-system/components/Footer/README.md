# Footer

The end of every page: a strip of the brand dot pattern, then secondary links and the studio line on `graphite`.

**Provide:** `<footer class="np-footer">`, then `<div class="np-footer__pattern" aria-hidden="true">`, then `np-footer__inner` holding a `<ul>` of links and an `np-footer__meta` line.

- Text, links and the focus ring are `on-graphite` (13:1 in light, 17:1 in dark), because `focus-ring` is too dark on `graphite`.
- The dot pattern is `neon` at the `space-6` pitch. It is the only decoration.
- Keep it to four or five links plus the studio line. The full contact details belong on the contact page.
