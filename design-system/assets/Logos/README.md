# Logos

The square neon logo: "NEON" (stretched to the width of "PURPLE"), "PURPLE" and a lowercase "studio" with a tube line, right-aligned inside one tube frame with rounded corners. Ink: `neon` (#a912ff). Lettering: Beon by NoirBlancRouge (SIL Open Font License), converted to outlines.

- `neon-purple-studio-logo.svg` / `.png` — the lit sign with halo and wall shadow on `paper` (#f7f5f2), 2048×2048.
- `neon-purple-studio-logo-dark.svg` / `.png` — the same on the dark wall (#141118): near-white tubes in a purple halo.
- `neon-purple-studio-mark.svg` — the square, flat in `neon`, transparent, no glow. 48px and up.
- `neon-purple-studio-wordmark.svg` — horizontal, flat, no frame: "NEON PURPLE" over "studio", in `neon` (#a912ff, 4.6:1 on `paper`). For light backgrounds: the site header and anything under 48px tall; minimum 24px tall.
- `neon-purple-studio-wordmark-dark.svg` — the same wordmark in dark-theme `neon-ink` (#d4a1ff, 9.2:1 on the dark `paper`), for dark backgrounds. The light file drops to 3.8:1 there and its thin "studio" is hard to read.

Works on `paper`, `surface`, `ink` and `graphite`. Not on `neon` or `neon-tint`.
