# Content

This folder is the website's content and an Obsidian vault. Open it in Obsidian with **Open folder as vault**.

- `projects/`: one note per project, shown under Work.
- `posts/`: one note per post, shown under Writing.
- `pages/`: the text of the home, about and contact pages.
- `_templates/`: the starting point for a new project or post (Obsidian: **Insert template**).

Anything with `draft: true` never appears on the live site.
