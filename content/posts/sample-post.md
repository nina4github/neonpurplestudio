This is a **sample post**. It has `draft: true`, so it only shows while you run the site locally.

To publish a real post, copy this file, change the frontmatter, write, and set `draft: false`.

Images go in `content/posts/images/` and are linked like this: `![What the image shows](./images/my-image.jpg)`.
